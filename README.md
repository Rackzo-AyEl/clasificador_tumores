# Clasificador y segmentador de tumores cerebrales
En este proyecto se buscan métodos confiables trabajar sobre visión artificial con imágenes médicas que requieren una alta precisión y confiabilidad para la clasificación y segmentación de tumores cerebrales usando MIR (Imágenes de resonancia magnética).
Las redes propuestas sobre este trabajo son MLP junto a ResNet50 para clasificación y U-Net con EfficientNet para la segmentación
